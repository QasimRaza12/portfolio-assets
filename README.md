# portfolio-assets

Draco-compressed GLB models for my portfolio site, served through jsDelivr:
`https://cdn.jsdelivr.net/gh/QasimRaza12/portfolio-assets@main/<file>.glb`

Materials are not embedded; the site applies the textures itself.
